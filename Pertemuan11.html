01 · Pengenalan

Apa itu Kubernetes?

Kubernetes (K8s) adalah platform open source untuk mengorkestrasi container: menjadwalkan, menjalankan, menskalakan, memperbarui, dan memulihkan aplikasi container secara otomatis di sekumpulan server (cluster).

🔤 Nama dari bahasa Yunani κυβερνήτης = juru mudi / pilot kapal. K8s: huruf K + 8 huruf + s.
📜 Sejarah singkat
2003+Google menjalankan sistem internal Borg untuk mengelola miliaran container.
2014Google merilis Kubernetes sebagai open source, terinspirasi Borg.
2015v1.0 rilis; Kubernetes menjadi proyek pertama CNCF (Cloud Native Computing Foundation).
2022v1.24 menghapus dockershim; runtime kini lewat CRI (containerd/CRI-O). Image buatan Docker tetap berjalan.
2026Rilis terbaru v1.37 "Garhwal" (26 Agustus 2026); ±3 rilis per tahun.

🎯 Apa yang dikerjakan Kubernetes untuk kita?
🔁 Self-healing: container mati → dibuat ulang otomatis
📈 Auto-scaling: tambah/kurangi replika sesuai beban
🚀 Rolling update & rollback tanpa downtime
⚖️ Service discovery & load balancing

07 · Deployment Strategy

Rolling update: ganti versi tanpa downtime

Strategi default Deployment: Pod baru dibuat sedikit demi sedikit, dan Pod lama baru dimatikan setelah Pod baru siap. Pengguna tetap terlayani selama proses. Ikuti langkah demi langkah.

deployment/web · replicas: 4 · maxSurge: 1 · maxUnavailable: 0tersedia: 4/4
Kondisi awal: 4 Pod versi v1 (nginx:1.26) melayani pengguna.
perintah
maxSurge: jumlah Pod ekstra yang boleh dibuat di atas jumlah replika. maxUnavailable: jumlah Pod yang boleh tidak tersedia selama update. Dengan 1/0 → kapasitas tidak pernah turun.
Versi baru bermasalah? kubectl rollout undo mengembalikan ke ReplicaSet sebelumnya dalam hitungan detik.

09 · Networking

Service: alamat tetap untuk Pod yang selalu berganti

Pod bisa mati dan diganti kapan saja (IP-nya berubah). Service memberi satu alamat stabil dan membagi request ke Pod yang sehat.

ClusterIP

Internal saja

Default. Hanya bisa diakses dari dalam cluster, misalnya backend → database (mysql:3306).

NodePort

Port di setiap node

Membuka port 30000–32767 di tiap node: http://IP-node:30080. Cocok untuk belajar/minikube.

LoadBalancer

IP publik dari cloud

Cloud (GKE/EKS/AKS) membuat load balancer eksternal otomatis. Untuk produksi; HTTP biasanya lewat Ingress.

⚖️ Simulasi load balancing

Tekan "Kirim 8 request". Angka kuning = jumlah request yang dilayani tiap Pod.
